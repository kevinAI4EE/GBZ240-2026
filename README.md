# GB/Z 240—2026 人工智能　电力智能体通用技术要求：原文与 AI 执行手册

这里有 GB/Z 240—2026 的原文，以及一份给 AI 照着做的执行手册。你不用自己读标准：把手册发给 ChatGPT、Claude、DeepSeek、Kimi 这类 AI，告诉它你要做什么，它会按手册里的步骤替你干活。

## 文件

| 文件 | 给谁 | 内容 |
|---|---|---|
| `GBZ240-2026_for-AI.md` | AI | AI 执行手册。合规自查、按标准设计、部署前测试、关键结论校验、条款问答五个流程，每一步写明做什么、输出什么；后面附 90 条原文，带条款号 |
| `GBZ240-2026_人工智能_电力智能体通用技术要求.pdf` | 人 | 标准原文 |
| `GBZ240-2026.json` | 程序 | 90 条要求、术语、附录等结构化数据 |

## 怎么用

1. 把 `GBZ240-2026_for-AI.md` 作为附件发给 AI。能联网的 AI 也可以直接给它这个文件的 Raw 链接。
2. 附上你的材料，再说一句你要做什么：

| 你要做的事 | 这样跟 AI 说 |
|---|---|
| 检查现有方案 | 按手册 A1 合规自查，检查附件里的方案。 |
| 设计新的电力智能体 | 按手册 A2，帮我设计一个用于××的电力智能体。 |
| 出上线前的测试计划 | 按手册 A3，给这个智能体出一份部署前测试计划。 |
| 校验智能体给出的结论 | 按手册 A4，校验这个诊断结论：…… |
| 问某一条是什么意思 | 按手册 A5，第 5.6.1 条要求什么？ |

信息不够时，AI 会先列出问题问你；它给的每个结论都会带条款号。

**Claude Code 用户**：把文件改名为 `SKILL.md`，放进 `.claude/skills/gbz240-power-agent/` 目录，就能当 Skill 用，聊到 GB/Z 240 或电力智能体时会自动加载。

## 整理方法

- 手册 C 部分的原文由脚本从 PDF 文字层解析，每一条都回到 PDF 文字里核对过。只做了两处排版处理：`ITU⁃T`、`DL∕T` 里的特殊字符统一成 `-`、`/`；补回中文和数字、字母之间的空格。
- 附录 B 是表格，文字层顺序是乱的，手工整理后逐项回原文核对。
- 手册 A、B 部分的流程引用了 72 个条款号，脚本逐个核对过，都在原文里。
- 计数口径：每个 a)、b)… 列项记 1 条，没有列项的条记 1 条，引导语不计，共 90 条。
- 手册 D 部分列出了几处原文疑点（比如附录 A 的案例前后条件不一致），这是整理者的判断，供核对。
